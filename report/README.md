**Charts** for chapter 8 are in `../results/charts/` (generated by `tools/plot_results.py`). The full result tables are in `../results/RESULTS.md`. Insert at least one chart per experiment into the PDF: `exp1_time_vs_size.png` + `exp1_normalised.png`, `exp2_expanded_by_preset.png` + `exp2_grid_scaling.png`, `exp3_time.png` + `exp3_greedy_quality.png`, `exp4_heap_ops.png` + `exp4_ns_per_op.png`, `exp5_comparisons.png` + `exp5_topk.png`.

**Making the PDF.** Any of these works: open the Markdown files in VS Code with a "Markdown PDF" extension; paste them into Word or Google Docs and export to PDF; or install pandoc and run `pandoc 01_title.md … 10_conclusion.md -o report.pdf`. Save the result as `report/24I-3071_24I-3000_<Section>_Report.pdf`. `tools/package.ps1` warns if `report/` has no PDF.
